# Getting started

Use the [published setup guide](https://openathan.com/docs/getting-started/) to
compare the Waveshare AUDIO-Board, Waveshare Box V2, and M5Stack AtomS3R with
Voice Pyramid. The guide covers connecting the correct USB port, installing a
qualified release, joining home Wi-Fi, and reviewing the prayer timetable on
the speaker. It also explains how to find the settings page, update firmware,
or recover access to an existing speaker.

The [Astro setup page](../pages/docs/getting-started.astro) renders the guide.
Fresh installation is offered only with a matching published release and
requires explicit erasure confirmation. Existing-speaker settings and Wi-Fi
or password recovery use [USB setup](https://openathan.com/install/) without
reinstalling. Use the [preserving firmware update instructions](https://openathan.com/docs/getting-started/#firmware-updates)
for updates, or see [troubleshooting](https://openathan.com/docs/troubleshooting/)
for connection help.
